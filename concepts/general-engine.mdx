The General Engine is the default memory path for applications without a domain overlay. It accepts evidence, processes it asynchronously and retrieves current context for a stable owner. It can represent preferences, facts, goals, procedures, relationships and expertise.

It does not replace transcripts, document retrieval, business records or application authorization. Whether a candidate is durable or semantically related can involve model interpretation; a successful request is not a guarantee of the intended meaning.

## Write lifecycle

`add()` admits work and returns a job ID. The worker later extracts/reconciles candidates and persists outcomes. Publication can follow the database commit. A completed job may create records, create no record or buffer candidates. Inspect actual current reads before reporting a successful memory journey.

Use the [quickstart](/quickstart) for a submit-once/poll/read example and [lifecycle](/concepts/memory-lifecycle) for state meanings.

## Governed reads

Call `get()` before constructing an answer dependent on memory. Check visibility, scope/choice signals and passthrough first. Only then use `system_prompt_addition` as contextual data. Empty memory is not the same as a hold. See [visibility handling](/concepts/degradation).

Use a query describing the actual task. A returned text match does not certify that it supports every question or project; your application must validate answer relevance.

## Select an optional contract

- [Explicit scoped preferences](/guides/scoped-preferences): application supplies property/value/scope and exact replacement binding.
- [Registered service provenance](/concepts/provenance): owner-configured writers provide service evidence and authority policy.
- Domain overlays: EdTech/Support require their own enabled configuration and remain separate from the generic memory contract.

Start with the [Python](/sdk/python) or [TypeScript](/sdk/typescript) SDK. Hosted access and optional features must be confirmed for your assigned environment. No production-readiness claim follows from the existence of these interfaces.
