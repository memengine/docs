## Connect from your server

```python
import os
from memoryos import Memory, AsyncMemory

memory = Memory(
    api_key=os.environ["MEMORYOS_API_KEY"],
    base_url=os.environ["MEMORYOS_API_URL"],
)
```

`base_url` is the backend root, without `/v1`. Its SDK default is `https://api.memoryo.dev`; set it to your instance URL for self-hosting. An API key never belongs in browser code. Your server supplies a stable `external_user_id` after authenticating the user.

## Save and poll

The following is a **verification sequence**, not a per-response chat wait. Polling can wait up to the specified timeout. Use [chat lifecycle](/guides/chat-lifecycle) for ordinary background capture, correction ordering and processing-state UX.

```python
admitted = memory.add(
    external_user_id="synthetic-customer-123",
    conversation_id="synthetic-thread-1",
    idempotency_key="synthetic-thread-1-turn-1",
    messages=[{
        "role": "user",
        "content": "I prefer concise explanations.",
        "external_turn_id": "synthetic-thread-1-turn-1",
        "source_kind": "direct_user_input",
    }],
)
if admitted.status == "queued" and admitted.job_id:
    job = memory.wait_for_job(admitted.job_id, timeout=120, poll_interval=1)
    print(job.status, job.memories_created, job.created_memory_ids)
    print(job.pending_candidates_buffered)
else:
    print(admitted.status, admitted.blocked_reason)
```

Queued is admission, not storage. Inspect the original job; a completed job may create no records or retain a pending candidate. On a timeout, inspect that same job later. Reuse the same key and request for a network retry; do not create new operations to hide a failure. `was_stored` is a legacy convenience property, not evidence of application.

`add()` accepts optional `metadata`, `source` and `preference_claims`. Do not label assistant/tool/document output as direct user input. The application must preserve actual evidence origin; a role or metadata value cannot grant higher authority.

## Read and gate

```python
result = memory.get(query="How should I explain this?", external_user_id="synthetic-customer-123")
if result.memory_visibility is not None:
    print("Context processing or unavailable; withhold dependent answer.")
elif result.preference_scope_request is not None or result.preference_decisions:
    print("Scope or explicit user choice required.")
elif result.is_passthrough:
    print("Memory bypassed; apply the application's no-memory policy.")
else:
    for record in result.items:
        print(record.id, record.content, record.source_event_id)
    # Only now consider result.system_prompt_addition for the model request.
```

Read properties include `items`, `has_context`, `system_prompt_addition`, `retrieval_id`, `cached`, `quota_mode`, `is_degraded`, `is_passthrough`, `memory_visibility`, `clarification`, `source_reviews`, `preference_reviews`, `preference_decisions` and `preference_scope_request`.

`get()` supports `limit`, `categories`, `format`, `context_max_tokens`, `time_filter_days`, timezone-aware `as_of` and `preference_context`. Explicit preference context cannot be combined with historical `as_of` or agent-bound SDK reads. See [scoped preferences](/guides/scoped-preferences) and [visibility](/concepts/degradation).

## Respond to a source review

```python
# selected_action must be the actual user's selection from this card's actions.
answer = memory.answer_source_review(
    review_id=card.id,
    external_user_id="synthetic-customer-123",
    version=card.version,
    action=selected_action,
)
print(answer.resolved, answer.next_step)
```

`keep_current` and `dismiss` close an eligible review without storing pending text. `restate` returns `resolved=False`, `next_step="add_memory"`: it requests a new statement, not a completed correction. For an intentional typed replacement, supply the actual target ID/version under the [replacement contract](/guides/scoped-preferences). Do not invent bindings from a similarity search or silently resolve a review with model output.

Source review is separate from A/B clarification (`answer_clarification()`) and administrative service correction. See the [native review contract](/api-reference/retrieve#review-an-uncertain-source-statement-in-your-existing-chat) for refusal behavior and card handling.

## Registered service events

```python
source = Memory.source(
    "billing-service",
    event_id="synthetic-subscription-event-1",
    observed_at="2026-11-24T09:00:00Z",
    scope={"account_id": "synthetic-account-1"},
)
```

Pass `source=source` to `add()` only after the owner registers that writer and binds appropriate credentials/policy. Normal chat applications can omit it. A source-aware event uses a different authority path from ordinary conversation evidence. See [provenance](/concepts/provenance).

## Async client

```python
async def read_context(owner):
    async with AsyncMemory(
        api_key=os.environ["MEMORYOS_API_KEY"],
        base_url=os.environ["MEMORYOS_API_URL"],
    ) as client:
        result = await client.get(query="What is current?", external_user_id=owner)
        return result  # Apply the same visibility/scope/choice gate before use.
```

The async client exposes corresponding awaited write, job, retrieval and review methods. Close the sync client with `memory.close()` or a `with` block; use `async with` for the async client.

## Other contracts

- `get_job_status()` / `wait_for_job()`: inspect the original admission.
- `list()`: authorized management listing; use the native history endpoint for version history, not as current answer context.
- `feedback()`: optional retrieval outcome reporting; a correction can queue another job.
- Delete/export and domain helpers: require their endpoint-specific permissions and enabled configuration.

`UniversalMemory` belongs to disabled-by-default Memory Passport. Assistant-proposal confirmation and automatic interpretation are experimental; their presence in source or types does not enable them. Check the feature configuration of your backend.
