## 1. Choose simulation or a real backend

### No-key simulation

From a fresh clone of the [repository](https://github.com/memengine/memory-api):

```bash
git clone https://github.com/memengine/memory-api.git
cd memory-api
python examples/demo/run.py
```

This uses local fixtures and requires no SDK, API key, model or running backend. It demonstrates the shape of a governed-context workflow. It does **not** verify ingestion, authentication, retrieval or model behavior. Keep simulation results separate from live evidence.

### Real integration

Create a workspace and API key in the [dashboard](https://app.memoryo.dev), then follow [Integration setup](/guides/integration-setup). Use `https://api.memoryo.dev` for the hosted API or your own instance URL for self-hosting.

For self-hosted exploration, follow the repository's [local beta instructions](https://github.com/memengine/memory-api/blob/main/beta/README.md). That profile uses isolated Docker resources and exposes its API at `http://127.0.0.1:18000`. Dependency/image downloads need internet. Ingestion and some retrieval paths can use paid extraction/embedding providers; a chat-model stub alone does not make the backend free.

Do not reuse another project's database, queues or credentials. No agent registration, Memory Passport or Clerk account is required for the tenant API-key example below.

## 2. Install the SDK and configure your server

<CodeGroup>

```bash Python
pip install memoryo-sdk==0.1.2
```

```bash TypeScript
npm install memoryo-sdk@0.1.3
```

</CodeGroup>

Set `MEMORYOS_API_KEY`, `MEMORYOS_API_URL` and `MEMORYOS_TEST_OWNER` in your server environment. Set `MEMORYOS_API_URL=https://api.memoryo.dev` for hosted use, or use your self-hosted API root without a trailing `/v1`; use the backend API address, not a dashboard or MCP gateway URL. Keep credentials out of browser code and source control.

## 3. Submit once and inspect the original job

Use one fresh synthetic owner and keep its ID stable when reopening the application. The sample statement is evidence for extraction, not a forced storage result.

<CodeGroup>

```python Python
import os
from uuid import uuid4
from memoryos import Memory

owner = os.environ["MEMORYOS_TEST_OWNER"]
with Memory(
    api_key=os.environ["MEMORYOS_API_KEY"],
    base_url=os.environ["MEMORYOS_API_URL"],
) as memory:
    admitted = memory.add(
        external_user_id=owner,
        messages=[{"role": "user", "content": "I prefer concise explanations."}],
        idempotency_key=str(uuid4()),
    )
    if admitted.status != "queued" or not admitted.job_id:
        raise RuntimeError("Write was not queued; inspect status and blocked_reason.")
    job = memory.wait_for_job(admitted.job_id, timeout=120)
    print(job.status, job.memories_created, job.pending_candidates_buffered)
    if job.status != "completed":
        raise RuntimeError("Processing failed; preserve the original job ID.")
```

```ts TypeScript
import { randomUUID } from "node:crypto";
import { MemoryOS } from "memoryo-sdk";

function required(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`Missing ${name}`);
  return value;
}
const owner = required("MEMORYOS_TEST_OWNER");
const memory = new MemoryOS(required("MEMORYOS_API_KEY"), required("MEMORYOS_API_URL"));
const admitted = await memory.add({
  externalUserId: owner,
  messages: [{ role: "user", content: "I prefer concise explanations." }],
  idempotencyKey: randomUUID(),
});
if (admitted.status !== "queued" || !admitted.jobId) {
  throw new Error("Write was not queued; inspect status and blockedReason.");
}
const job = await memory.waitForJob(admitted.jobId, { timeoutMs: 120_000 });
console.log(job.status, job.memoriesCreated, job.pendingCandidatesBuffered);
if (job.status !== "completed") throw new Error("Processing failed; retain the original job ID.");
```

</CodeGroup>

If polling times out, retain the job ID and inspect it later. Do not submit another save merely to make polling succeed. A new key is a new operation. For a network retry, reuse the same key and identical authorized request; see [write replay](/api-reference/add#retry-and-replay-boundary).

## 4. Retrieve before answering

Use the same client/owner variables as above, in the same process or after reopening with the same environment.

<CodeGroup>

```python Python
with Memory(
    api_key=os.environ["MEMORYOS_API_KEY"],
    base_url=os.environ["MEMORYOS_API_URL"],
) as memory:
    result = memory.get(query="How should you explain things to me?", external_user_id=owner)
    if result.memory_visibility is not None:
        print("Memory context is processing or unavailable; do not answer from it.")
    elif result.preference_scope_request is not None or result.preference_decisions:
        print("Obtain the application's scope or the user's explicit choice first.")
    elif result.is_passthrough:
        print("Memory is bypassed; decide whether this request can proceed without it.")
    else:
        print([(record.id, record.content) for record in result.items])
        print(result.system_prompt_addition)
```

```ts TypeScript
const result = await memory.get({ query: "How should you explain things to me?", externalUserId: owner });
if (result.memoryVisibility) {
  console.log("Memory context is processing or unavailable; do not answer from it.");
} else if (result.preferenceScopeRequest || result.preferenceDecisions?.length) {
  console.log("Obtain the application's scope or the user's explicit choice first.");
} else if (result.isPassthrough) {
  console.log("Memory is bypassed; decide whether this request can proceed without it.");
} else {
  console.log(result.items.map(record => ({ id: record.id, content: record.content })));
  console.log(result.systemPromptAddition);
}
```

</CodeGroup>

A completed job can still be followed by processing visibility while publication catches up. Do not report successful recall until a subsequent authorized read actually returns the expected current record. These examples make no chat-model calls.

For corrections, inspect [source review](/api-reference/retrieve#review-an-uncertain-source-statement-in-your-existing-chat) or the [explicit preference contract](/guides/scoped-preferences), rather than assuming a second sentence automatically replaces the first.
